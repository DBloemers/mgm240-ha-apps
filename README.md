# Nano Matter ESPHome experiments

Add this repository URL under **Settings → Apps → Install app → Repositories**
in Home Assistant OS.

```text
https://github.com/DBloemers/mgm240-ha-apps#store
```

Select **ESPHome Device Builder (Nano Matter)** and install it. The app uses
a prebuilt image for AMD64 and ARM64. The build recipe and CI workflow are on
the [main branch](https://github.com/DBloemers/mgm240-ha-apps/tree/main).
